# AI Diary Backend

FastAPI + SQLAlchemy + Alembic. **Supabase PostgreSQL** is the team's chosen shared database. SQLite is used only for isolated automated tests or explicitly requested offline development.

Start with [Supabase setup](../docs/SUPABASE_SETUP.md) to create the project and configure your untracked backend/.env file.

## Quickstart (Windows PowerShell)

~~~powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
# Edit .env and replace placeholders with your Supabase Session pooler URL.
python -m scripts.check_db
alembic upgrade head
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
~~~

On macOS/Linux, activate with `source .venv/bin/activate` and copy `.env.example` using `cp`.

- Swagger: http://127.0.0.1:8000/docs
- Health: http://127.0.0.1:8000/health
- Android Emulator connects to backend at http://10.0.2.2:8000/api/v1

**Never embed the Supabase database URL or password in Flutter or commit .env.** The API server alone owns database access.

## Migrations

The app does not create tables at startup. Run `alembic upgrade head` first.

`MIGRATION_DATABASE_URL` can optionally specify a **direct** Supabase Postgres connection for migrations (recommended when your machine has IPv6). Otherwise Alembic uses `DATABASE_URL` (session pooler over IPv4).

~~~bash
alembic current
alembic check
alembic revision --autogenerate -m "describe schema change"
# Review autogenerated file before applying it!
alembic upgrade head
~~~

`alembic check` is used against a database already migrated to the current head. Only run migrations once against the team's shared Supabase project; coordinate schema changes using a PR.

## Tests

~~~bash
pytest -q
~~~

The test suite uses a temporary SQLite file and never connects to Supabase. It is safe to run without a live Supabase project.

## Existing local SQLite database

If you have an old `ai_diary.db`, do not delete it unless you explicitly want to discard its data. This does not affect the new Supabase project. To migrate data, plan a separate export/import task.

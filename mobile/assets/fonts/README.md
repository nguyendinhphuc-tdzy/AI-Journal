# App typography

- Nunito: display, headline and title styles (400–800).
- Be Vietnam Pro: body, labels, controls and journal input (400–700, regular italic).

Font files are bundled for offline use; no runtime font downloads or extra packages.
Each family includes its SIL Open Font License in `OFL.txt`.

Sources:
- Nunito static TTFs: https://fonts.googleapis.com/css?family=Nunito:400,500,600,700,800&subset=vietnamese
- Nunito license: https://github.com/google/fonts/tree/main/ofl/nunito
- Be Vietnam Pro: https://github.com/google/fonts/tree/main/ofl/bevietnampro

Downloaded 2026-10-13. Register new weights in `mobile/pubspec.yaml` before use.
